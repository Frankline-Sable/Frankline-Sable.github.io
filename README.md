# 👓 Frankline Sable — Software Engineering Portfolio

Welcome to my personal portfolio repository! This is where I showcase my software engineering journey, professional experience, technical skills, and projects across **backend, full-stack, mobile, and cloud development**.

The repository hosts two distinct versions of my portfolio, each with its own design and presentation style.

## 🌐 Live Portfolios

| Version | Description | Hosting |
|---|---|---|
| [Original Portfolio](https://frankline-sable.github.io/) | My original creative portfolio, featuring interactive animations, artwork, and a broader collection of projects. | GitHub Pages |
| [Modern Portfolio](https://frankline-sablegithubio.vercel.app/) | A redesigned, engineering-focused portfolio highlighting my technical experience, architecture, and selected projects. | Vercel |

Both versions are built using **vanilla HTML, CSS, and JavaScript**, without frontend frameworks.

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript
- **Design:** Responsive layouts, CSS animations, and interactive UI components
- **Version Control:** Git & GitHub
- **Hosting & Deployment:** GitHub Pages and Vercel

## 🌿 Branch Structure

Both portfolios are maintained independently within the same repository.

```text
Frankline-Sable.github.io
│
├── master
│   └── Original Portfolio
│       └── GitHub Pages
│
└── vercel-portfolio
    └── Modern Portfolio
        └── Vercel
```

Changes pushed to each branch are deployed to their respective hosting platforms.
